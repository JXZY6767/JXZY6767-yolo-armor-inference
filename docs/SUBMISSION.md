# 作业提交检查清单

截止时间：**2026 年 10 月 18 日 00:00（北京时间，UTC+8）**，即 10 月 17 日周六结束时。以下是操作清单，不表示仓库、PR 或作业页面已经提交。

## 1. 创建公开仓库与开发分支

- 在自己的 GitHub 账号下创建 Public 仓库，名称可使用 `yolo-armor-inference`。
- 初始化主分支 `main` 和简短的 README。
- 从 `main` 创建开发分支 `feat/yolo-inference`。
- 在开发分支添加本次实际代码、依赖、完整 README、`.gitignore` 和 `docs/`。
- 模型、视频、虚拟环境和 `runs/` 不加入 Git 历史；通过网页上传时也不要选这些文件。

## 2. 本地与提交前检查

- [ ] README 的运行命令与实际文件名一致。
- [ ] 依赖安装成功，推理命令能执行。
- [ ] 结果视频可以打开并完整播放，与原视频内容对应。
- [ ] 能看见检测框、类别、置信度及模型预测的四个关键点。
- [ ] README 中的截图在 GitHub 上可以显示。
- [ ] 保留并说明漏检、模糊和关键点偏差，没有虚构平均置信度或识别准确率。
- [ ] Git 差异中包含 `infer.py`、依赖清单和完整 README。

## 3. 发起并合并 PR

从自己的仓库创建 PR：`base: main`，`compare: feat/yolo-inference`。

可使用以下标题：

> 完成装甲板视频推理与关键点显示

在实际代码与这些文档一起提交的前提下，可使用以下 PR 描述，并按最终运行情况调整：

```text
实现指定 YOLO26n 装甲板模型的视频推理，支持配置权重、视频、输出目录和设备，保存检测框、类别、置信度及模型预测的四个关键点。

补充依赖清单、安装和运行步骤、D414 自行拍摄情况、代表性结果截图与问题记录；忽略权重、视频、虚拟环境和推理输出。

验证：对本人拍摄的约 16.83 秒视频运行推理，现有结果视频的 505 帧可连续解码。逐帧标签共 710 条检测记录，504 帧有检测；第 322 帧运动模糊且未检出目标。README 保留正常检测与漏检截图，说明未进行人工真值评测，未声称平均置信度或准确率。
```

检查 Files changed 确实包含本次推理功能的实际改动，然后由本人完成合并。确认 PR 显示 **Merged**，`main` 包含完整代码和文档。只修改无关文字的 PR、未合并的 PR 或仅有 commit/push 均不满足要求。

```text
推理结果视频：Robot_test .avi
拍摄地点：水建学院 D414 实验室，本人独立拍摄
时长：约 16.83 秒
```

上传原始视频与结果视频两个附件，检查链接公开有效、PR 为 Merged、视频可播放。当前原始视频约 32.23 MiB、结果约 45.02 MiB，均低于单视频 100 MiB 限制。AVI 是作业允许的视频格式；若作业页面无法预览当前编码，先转换为兼容的 MP4 并完整检查后再上传，不能只改扩展名。

选择附件后，还要点击“提交作业”并确认。重新提交时选择完整的一组附件。
